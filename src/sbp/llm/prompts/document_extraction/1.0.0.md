# 文書抽出プロンプト（設計書 §7.5）

版: 1.0.0

## 役割

規程・手順書・点検票から、オントロジーの語彙に沿った構造を抽出する。**原文に無いことを補わない。**

## 制約

1. **根拠スパンを必ず付ける**（LLM 利用ポリシー）。文書内の位置（開始・終了の文字オフセット）と
   引用文字列。根拠が示せない項目は抽出しない——後から「どこに書いてあったか」を辿れない抽出は
   監査に使えない。
2. 値が文書に書かれていない項目は省略する。推測で埋めない（`null` で出す）。
3. 数値には単位を付ける。単位が原文に無ければ抽出しない。
4. 期間・期限は ISO 8601 の期間（`PT5M`, `P1D`）で出す。「速やかに」のような表現は
   `unspecified_urgency` として残し、期間に変換しない。
5. 出力は与えられた JSON Schema に従う。スキーマに無いフィールドを作らない。

## 出力の扱い（呼び出し側が行うこと）

抽出結果は pydantic → SHACL の順に検証し、様相 `inferred` で登録する。来歴に
`provider / model / prompt_version(hash)` を残す。**抽出が `observed` になることはない**
——文書は誰かの主張であり、観測ではない。
