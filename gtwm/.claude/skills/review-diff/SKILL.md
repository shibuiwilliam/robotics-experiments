description: 現在のブランチの差分を CLAUDE.md とルールに照らしてレビューする。修正はしない。

引数: $ARGUMENTS（省略時は `main...HEAD`。ファイルやコミット範囲を指定可）

1. `git diff <範囲>` を読む。
2. 次の観点で指摘する：CLAUDE.md と `.claude/rules/` の違反、盲検境界の侵害（`grounding/` `wm/` から注入台帳を参照）、閾値・重み・モデル名のハードコード、テストの欠落、MPS で動かない可能性のある op や bf16、GUI ウィンドウを開くコード、長時間ジョブのフォアグラウンド実行、`print` の使用、400行超のファイル。
3. 指摘は「ファイル:行 / 問題 / 修正案」の形式で重要度順に並べる。問題がなければ「指摘なし」と書く。
4. 修正はしない。ユーザーが指示したら別途対応する。
