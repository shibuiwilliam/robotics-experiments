# ADR-0001: SBP を独立リポジトリとする

- 日付: 2026-10-03
- 状態: 採択
- 触る層: infra（リポジトリ構成）

## 文脈

SBP は親ディレクトリ `robotics-experiments/` の未追跡サブディレクトリとして存在していた。`CLAUDE.md` は「本リポジトリは基盤本体のみ。ユースケース検証（実機・サンドボックス実験）は別リポジトリで行い、ここには入れない」と定めており、親リポジトリは性質上ユースケース実験の集合である。`docs/TASK.md` §7-1 の未決事項。

## 選択肢

1. **SBP ディレクトリで `git init` し独立リポジトリにする** — 利点: CLAUDE.md の前提（基盤本体のみ）と一致し、オントロジー版・`make check` の CI 境界がリポジトリ境界と揃う。履歴が実験コードと混ざらない。欠点: 親リポジトリ側から見ると入れ子の未追跡ディレクトリが残る。MacBook 上のコスト: なし。
2. 親リポジトリのサブディレクトリとして追跡する — 利点: 単一履歴。欠点: 実験コードの履歴と基盤の履歴が混ざり、オントロジー semver の CI 境界が曖昧になる。ユースケース検証を混入させない規律が機械的に保てない。
3. git submodule にする — 利点: 両立。欠点: この規模では運用コストが利益を上回る（submodule の更新忘れが典型的な事故源）。

## 決定

選択肢 1 を採る。`git init -b main` + `.gitignore`（`.env` 系・Python キャッシュ・ツールキャッシュ・ローカル生成物）で独立リポジトリ化し、既存ドキュメント一式を初回コミットとした。

`.gitignore` では `.env` と `.env.*` を除外しつつ `!.env.example` で例外化している（不変条件 12: シークレットは `.env` のみ、`.env.example` は必ず同期してコミット）。

親リポジトリ側に SBP が未追跡ディレクトリとして残る点は許容する（親側の `.gitignore` 調整は親リポジトリの関心事であり、本リポジトリの決定範囲外）。

## 影響

- 不変条件への影響: 12（シークレット）を `.gitignore` で機械的に担保。他の不変条件には影響しない。
- オントロジー版: 影響なし（`ontology/VERSION` は未作成）。再接地不要。
- テスト・運用への影響: CI（`X-01`）の対象リポジトリがここに確定する。`make check` の実行単位＝リポジトリ単位。

## 未決

なし。
