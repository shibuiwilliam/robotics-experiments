# コンピテンシー質問（CQ）

**CQはオントロジーの仕様であり、回帰テストである**（PROJECT.md §6）。
CQに答えられなくなる語彙変更はリグレッションとみなす。

## 記述形式（P0で確定予定）

各CQは1ファイル（YAML）で、次の3点を必ず持つ:

1. `question` — 自然言語の質問（日本語可）
2. `sparql` — 期待されるSPARQLクエリ（世界グラフに対して実行）
3. `truth` — 真値導出規則（oracle の真理グラフから正解を機械的に導く方法）

実行: `uv run pytest tests/cq -q`

詳細な書式は P0 の CQ フレームワーク実装時にここへ追記する。
