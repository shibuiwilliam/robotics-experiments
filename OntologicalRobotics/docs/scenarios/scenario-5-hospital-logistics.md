## 1. 叙述

薬剤・検体・リネンを搬送するロボット群。次の規範が**法的・運用的に強制**される:

- 麻薬及び向精神薬は**施錠区画から施錠区画へ**、受け渡しの**完全な保管の連鎖（chain of custody）**
  記録が要求される。
- 検体は「取り違え＝重大事故」なので、**同一性保証**が至上命題。
- 廊下では**人間と医療カートが常に優先**。

「このロボットは、この物を、この経路で運んでよいか」が、**物の分類 × 区画の属性 × 時間帯 ×
ロボットの認証状態**の積として規範オントロジーから導かれる。

## 2. なぜオントロジーが必要か（試金石への適合）

- 試金石③（規範と監査）が主役。前回構想した**規範層（deontic制約：許可/禁止/義務）**を初めて
  主検証対象にできる。
- 二つの評価が成功率とは別の軸で要求される:
  - **事前禁止**: 計画時に規範推論で違反行動を**事前に**禁止できたか。
  - **事後監査**: 監査クエリ（例「先週の麻薬搬送の全 custody 連鎖を示せ」）に**完全回答**できたか。
- これは成功率では測れない **監査可能性（auditability）** という新しい評価軸を導入する。

## 3. 反証可能な予言（オントロジー無しの失敗）

> **帰無仮説1（規範）**: 規範を持たない/コードに散在させた構成は、規則変更に追従できず、
> 違反行動（無認証搬送・非施錠経路）を事前に止められない。
> **帰無仮説2（監査）**: 来歴・規則を一元的な知識として持たない構成は、custody 連鎖の監査クエリに
> 完全回答できず、監査可能性が頭打ちになる。

- **B0 / B1**: 規範はプロンプト内の自然文に埋もれ、区画属性×物分類×認証の積で機械的に判定でき
  ない。違反の取りこぼし・誤許可が出る。custody 連鎖の事後完全再構成も不能。
- **OR−belief**: 来歴が貧弱だと custody 連鎖（誰がいつ受け渡したか）が途切れる。
- **OR-full＋規範層**: 計画時に deontic 推論で違反を事前棄却、事後監査に完全回答。

## 4. ORXへの縮約

| 要素 | 縮約方法 |
|------|----------|
| 世界（C1） | ゾーンに属性（`locked` / `corridor` / `ward`）。施錠区画・廊下を持つレイアウト |
| 物の分類 | 物体に `class`（narcotic / specimen / linen）。検体は ID無し取り違えリスク |
| 認証状態 | ロボットに `clearance`（認証レベル・時間帯制約） |
| 規範オントロジー | **新規** `orx-norm:`（Permission/Prohibition/Obligation、対象×区画×時間×認証）。**提案** |
| custody連鎖 | 受け渡しを `orx-prov:` 拡張イベントで記録（誰→誰、いつ、どの物） |
| 規範推論 | 計画時に SPARQL＋アプリロジックで許可/禁止を導出（重い推論器は使わない＝§6方針） |
| 触れるC | C1（区画属性）, C3（規則・認証台帳）, C5/C6（同一性＋custody記録）, C7（規範制約付き計画）, C8, C10 |
| 劣化ノブ | `id_read_failure_rate`（検体取り違えの誘発）, `contradiction_rate`（custody途切れ） |

## 5. タスク定義（採点）

二つの採点軸を併設する:

- **事前禁止（計画品質）**: 違反搬送の発生数（少ないほど良い）、正当タスクの完遂率。
  - 真値（C8）: 区画属性×物分類×認証の積から、各時点で許可される搬送集合を機械導出。
- **事後監査（監査可能性）**: 監査クエリ集（custody連鎖・違反履歴・特定物の経路）への
  **完全回答率（completeness）** と正答率。検体の同一性 F1（取り違えゼロが至上命題）。

## 6. 実験条件

| 条件 | 期待 |
|------|------|
| B0 / B1 | 規範が自然文に埋もれ、違反取りこぼし・監査不完全 |
| OR−belief | custody 連鎖が途切れ、監査完全性が低下 |
| **OR-full＋規範層** | 事前禁止が機能、監査クエリに完全回答 |

## 7. 指標

- 違反搬送発生数（事前禁止の質）・正当タスク完遂率
- **監査クエリ完全回答率（auditability）** — 本シナリオ固有の新軸
- 検体の同一性 F1（取り違え＝0 目標）
- 規則変更に対するメタモルフィック頑健性（規則の言い換えで判定不変）

## 8. 既存資産との関係

- 既存 C6 の来歴（`orx-prov:`）を custody 連鎖へ拡張。C7 の計画ループに**事前制約フィルタ**を追加。
- T1/T4 の同一性・信念調停を再利用するが、**規範層は新規実装**であり既存資産だけでは閉じない。
