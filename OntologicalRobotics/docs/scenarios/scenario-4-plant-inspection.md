# シナリオ4：プラント点検——図面上の設備と眼前の設備の同一化

| 項目 | 値 |
|------|-----|
| 主試金石 | **① 越境同一性（ID無し）** ＋ **信念調停** |
| 中核仮説 | **H2**（同一性解決）, **H5**（信念管理：機体間の矛盾観測） |
| 提案タスクスイート | **T11 設備同一化点検** |
| ORX縮約コスト | **中**（ID無し同一化） |
| ステータス | 候補 |
| 提案世界/実験 | `configs/world/s4_plant.yaml` / `configs/experiments/s4_plant.yaml`（未作成） |

## 1. 叙述

化学プラントの点検で、**ドローンが上方から**、**地上ロボットが近接から**設備を観測する。
資産台帳と P&ID（配管計装図）には「**バルブ V-205**」が定義されているが、ロボットが見ているのは
錆びた金属の塊にすぎない。同一化に成功して初めて、

```
知覚個体 ──anchoredTo──▶ 資産(V-205) ──該当系統──▶ 操業手順書(SOP) ──▶ 作業指示の起票
```

という連鎖が動く。さらに二機の観測が矛盾しうる（ドローンは「正常」、地上機は「滲みあり＝異常」）。

## 2. なぜオントロジーが必要か（試金石への適合）

- **「図面上の記号的存在」と「知覚された物理個体」の同一化（アンカリング）こそが業務価値のすべて**。
  バーコードに頼れない**ID無し同一性解決**（試金石①の難しい版）— 位置・形状・視覚署名と台帳の
  空間レイアウトを突き合わせる確率的アンカリング。
- 異常検知の主張には**観測来歴**（どの機体が・どの角度から・どの確信度で）が必須。二機の矛盾は
  信念調停（H5）の現実的な題材で、来歴・確信度に基づいて「どちらの主張を採るか」を決める。

## 3. 反証可能な予言（オントロジー無しの失敗）

> **帰無仮説1（H2）**: ID（バーコード）に頼る同一化は、ID無し設備では機能せず、知覚個体を台帳の
> 資産に結べないため SOP参照・作業起票の連鎖が起動しない。
> **帰無仮説2（H5）**: 来歴・確信度を持たない構成は、二機の矛盾観測を調停できず、誤った側を
> 採用して誤起票（または見逃し）する。

- **B0 / B1**: 台帳と知覚を結ぶ確率的同一性が無く、「眼前の塊＝V-205」を確定できない。
- **OR−identity**: ID無し個体で同一性 F1 が崩れ、空間的に近い別資産へ誤接続。
- **OR−belief**: 矛盾観測の調停ができず、確信度の低い観測に引きずられる。
- **OR-full**: 空間レイアウト＋視覚署名で台帳資産へアンカー、来歴調停で矛盾を解消。

## 4. ORXへの縮約

| 要素 | 縮約方法 |
|------|----------|
| 世界（C1） | 設備をプリミティブ形状（バルブ＝円柱＋ハンドル等）で模す。**バーコード無し**個体 |
| 資産台帳 | SQLite（C3）に資産（V-205 等）＋空間レイアウト（公称位置）＋系統・SOP参照 |
| 二機観測 | 上方カメラ（ドローン）＋近接カメラ（地上機）。視点が異なり遮蔽・確信度が変わる |
| 異常 | 一部設備に「滲み」テクスチャ。地上機は検出、ドローンは見落とす設計（矛盾を作る） |
| 同一化 | C5 を**台帳資産への**アンカリングに拡張（公称位置＋視覚署名のスコア融合、D1の応用） |
| オントロジー追加 | `orx-biz:Asset`, `orx-biz:partOfSystem`, `orx-biz:appliesTo`（SOP↔資産クラス）。**提案** |
| 触れるC | C1, C3（台帳）, C4/C5（ID無し同一化）, C6（来歴調停）, C7（SOP参照・起票）, C8, C10 |
| 劣化ノブ | `pose_noise_sigma` / `occlusion_rate` / `contradiction_rate` を機体別に掃引 |

## 5. タスク定義（採点）

- **入力**: 二機の観測記録（C9）＋ 資産台帳。
- **決定**: 各知覚個体→台帳資産の同一化、異常資産の特定、対応SOPの参照、作業指示の起票。
- **真値（C8 oracle）**: シム真値で各知覚個体の真の資産対応と真の異常状態を導出。
- **採点**: 同一性 F1（資産対応）、異常検知の precision/recall、SOP参照正答率、矛盾調停の正否。

## 6. 実験条件

| 条件 | 期待 |
|------|------|
| B0 / B1 | 台帳‐知覚の結合不能、連鎖が起動しない |
| OR−identity | ID無しで同一性 F1 劣化 |
| OR−belief | 矛盾観測の調停失敗 |
| **OR-full** | 同一化＋調停が成立、起票が正しく駆動 |

矛盾観測率の掃引（T4装置）で OR−belief との乖離を、ID無し条件で OR−identity との乖離を測る。

## 7. 指標

- 同一性 F1（ID無し）— 主指標
- 異常検知 precision/recall、矛盾調停の正否率
- SOP参照・起票の正答率、忠実度（同一化のトリプル採点）

## 8. 既存資産との関係

- **T1（同一性）** の C5/D1 を「台帳資産への同一化」に一般化（バーコード→公称位置＋視覚署名）。
- **T4（劣化）** の矛盾観測ノブと信念調停（C6）をそのまま使う。
- **T7（SOP検索）** のオントロジー誘導検索（資産クラス→SOP）が起票連鎖に接続する。

## 9. 実装メモ / コスト

- **中コスト**。ID無し同一化（バーコード不在で空間＋視覚に依存）と、台帳アンカリングへの C5 拡張が
  主作業。視覚署名は stub埋め込み or ローカルCLIP（C4）。
- シナリオ1より一段難しい同一性条件を検証できる。
