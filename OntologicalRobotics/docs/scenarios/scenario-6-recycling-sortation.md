# シナリオ6：リサイクル選別——法規制と知覚の橋渡し

| 項目 | 値 |
|------|-----|
| 主試金石 | **双対表現**（記号側＝規制推論 × ベクトル側＝視覚接地） |
| 中核仮説 | **H4**（双対表現が単独で業務成否を握る）。確信度較正（Brier）が実利に直結 |
| 提案タスクスイート | **T13 規制準拠選別** |
| ORX縮約コスト | **中**（視覚分類の作り込み） |
| ステータス | 採用推奨（3番手・H4分離が最も鮮明） |
| 提案世界/実験 | `configs/world/s6_recycling.yaml` / `configs/experiments/s6_recycling.yaml`（未作成） |

## 1. 叙述

廃棄物処理場に流れてくる物品には**IDがない**。

- リチウムイオン電池内蔵品は**発火リスク**のため特別レーンへ。
- フロン含有機器は**法令上の処理経路**へ。

ラベルなき物体を、**視覚埋め込み（双対表現のベクトル側）で候補クラスに接地**し、**規制
オントロジー（記号側）で処理経路を導出**する。誤分類のコストは非対称（電池の見逃しは火災）。

## 2. なぜオントロジーが必要か（試金石への適合）

- **H4（双対表現）が単独で業務成否を握る稀有な構図**。記号とベクトルの分業が必須:
  - **記号のみ（OR-sym）**: ID無し物体に記号属性を付与できず、候補クラスへ接地できない → 全滅。
  - **ベクトルのみ（OR-vec）**: 候補クラスは出せても、そこから法令処理経路を導く**規制推論**が
    できず誤レーンに流す。
  - **双対（OR-full）**: ベクトルで候補クラスに接地 → 記号（規制オントロジー）で処理経路を導出。
- 誤分類コストが非対称なので、**確信度に応じて人間に委ねる閾値設計**（確信度較正＝Brierスコア）が
  実利に直結する。

## 3. 反証可能な予言（オントロジー無しの失敗）

> **帰無仮説（H4）**: 記号のみ（OR-sym）はID無し物体で接地できず全滅し、ベクトルのみ（OR-vec）は
> 規制推論を欠いて誤レーン送りになる。双対表現の優位が最も鮮明に分離される。

- **OR-sym**（記号のみ）: バーコード等の記号識別子が無く、クラス接地が起動しない → 分類不能。
- **OR-vec**（ベクトルのみ）: 視覚で「電池っぽい」までは出せても、「→ 特別レーン（法令）」への
  記号推論が無く、規制準拠の処理経路に乗せられない。
- **OR-full**: ベクトル接地 × 規制オントロジーで規制準拠の正しいレーンへ。
- 非対称コスト: 電池見逃し（false-negative）は火災。recall を最優先＋確信度較正で人手委譲。

## 4. ORXへの縮約

| 要素 | 縮約方法 |
|------|----------|
| 世界（C1） | **ID無し**物品（色/形で視覚的に区別可能なクラス：battery / freon / inert 等）。レーン＝ゾーン |
| 視覚接地 | C4 の埋め込み（stub or ローカルCLIP）で候補クラスへ最近傍接地。**双対表現のベクトル側** |
| 規制オントロジー | **新規** `orx-biz:RegulatedClass`, `orx-biz:disposalRoute`（クラス→レーン）。**提案** |
| 規制推論 | 接地クラス → SPARQL で処理経路（レーン）を導出。**記号側** |
| 確信度較正 | 接地確信度に閾値、低確信度は「人間に委譲」アクション（Brierで較正評価） |
| 触れるC | C1, C4（視覚埋め込み＝H4ベクトル側）, C5/C6（接地＋規制写像）, C7（レーン決定・委譲）, C8, C10 |
| 劣化ノブ | `occlusion_rate` / `pose_noise_sigma`（視覚難度を上げて H4 の効きを掃引） |

## 5. タスク定義（採点）

- **入力**: ID無し物品の観測列（C9）。
- **決定**: 各物品の処理レーン（または人間委譲）。
- **真値（C8 oracle）**: シム真値で各物品の真クラスと法令上の正レーンを導出。
- **採点**: レーン正答率、電池/フロン見逃し（false-negative）件数、委譲率と委譲後の正答、
  確信度の **Brierスコア（較正）**。

## 6. 実験条件

| 条件 | 期待 |
|------|------|
| **OR-sym**（記号のみ） | ID無しで接地不能 → ほぼ全滅 |
| **OR-vec**（ベクトルのみ） | 接地はするが規制経路を導けず誤レーン |
| **OR-full**（双対） | 接地×規制推論で規制準拠、見逃し最小 |

視覚難度（occlusion）の掃引で OR-vec と OR-full の差（規制推論の寄与）を、ID無し条件で OR-sym の
崩壊を測る。**OR-sym / OR-vec は本シナリオで初めて主検証対象になる**（既存実装には未導入）。

## 7. 指標

- レーン正答率（主指標）、電池/フロン見逃し件数（非対称コスト）
- Brierスコア（確信度較正）＋ 委譲閾値の運用曲線
- 視覚難度 × 条件の頑健性曲線（H4 の動作領域）

## 8. 既存資産との関係

- C4 の埋め込み（stub / CLIP）と C5 の双対表現（記号＋ベクトル併置）を H4 の主検証に使う。
- **OR-sym / OR-vec アブレーション条件は新規**（現状の条件は OR-full / OR−identity / OR−belief のみ）。
  C7/C10 に「記号経路のみ」「ベクトル経路のみ」のスイッチを追加する必要がある。

## 9. 実装メモ / コスト

- **中コスト**。視覚分類の作り込み（クラスが視覚的に分離可能な世界）と、OR-sym/OR-vec 条件の実装が
  主作業。規制オントロジーは `orx-biz:` の小拡張。
- 双対表現の優位を**最も鮮明に分離**できるアブレーション設計。**3番手で着手**。
