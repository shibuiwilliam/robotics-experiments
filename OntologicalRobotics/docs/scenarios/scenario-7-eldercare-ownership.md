# シナリオ7：介護施設——「所有」という知覚不可能な関係

| 項目 | 値 |
|------|-----|
| 主試金石 | **① 情報的関係**（純粋に観測不可能な所有・帰属） |
| 中核仮説 | **H2**（確率的同一性解決）, **H4**（視覚署名）, **H6**（業務‐物理結合） |
| 提案タスクスイート | **T14 所有物の同定と配達** |
| ORX縮約コスト | **中** |
| ステータス | 候補 |
| 提案世界/実験 | `configs/world/s7_eldercare.yaml` / `configs/experiments/s7_eldercare.yaml`（未作成） |

## 1. 叙述

施設内サービスロボットが「**佐藤さんの眼鏡を居室に届けて**」を遂行する。眼鏡そのものは知覚できても、
**「誰のものか」は世界をいくら観測しても見えない**。似た眼鏡が複数ある環境では、対象を一意に
特定するために、**所有関係 ＋ 最終目撃位置 ＋ 視覚署名**の三系統を統合した確率的同一性解決が要る。

## 2. なぜオントロジーが必要か（試金石への適合）

- **所有・帰属は純粋に情報的な関係**であり、入居者台帳・持ち物記録（業務側 C3）と物理個体
  （知覚側 C4/C5）の結合なしには一意に決まらない。世界をいくら観測しても「佐藤さんの」は見えない。
- 「**物理的に観測不可能な関係こそオントロジーの存在理由である**」という OR の思想を最も雄弁に
  体現する（試金石①の情報的関係版）。
- バーコード頼みのシナリオ1より人間的で難しい: 似た物体が複数あるとき、所有（記号）＋最終目撃
  （時空間）＋視覚署名（ベクトル＝H4）の三系統融合が必要。

## 3. 反証可能な予言（オントロジー無しの失敗）

> **帰無仮説**: 所有関係を持たない/知覚のみの構成は、見た目が同じ複数の眼鏡から「佐藤さんの」を
> 一意に選べず、誤配達する。

- **B0 / B1**: 「佐藤さん ↔ この眼鏡」の帰属を業務台帳と物理個体で結べず、見た目一致の候補から
  選べない（あるいは恣意的に選ぶ）。
- **OR−identity**: 複数の似た眼鏡が分裂/混同し、最終目撃位置を辿れない。
- **OR-vec のみ**: 視覚署名で「眼鏡らしさ」は出るが、所有（誰の）は記号関係なので決まらない。
- **OR-full**: 所有（記号）× 最終目撃（時空間）× 視覚署名（ベクトル）の融合で一意特定。

## 4. ORXへの縮約

| 要素 | 縮約方法 |
|------|----------|
| 世界（C1） | 居室ゾーン複数＋共用部。**見た目が近い同種物体**を複数配置（眼鏡＝小プリミティブ） |
| 入居者台帳 | SQLite（C3）に入居者・居室・持ち物記録（owner ↔ item、視覚署名のひな型） |
| 所有関係 | **新規** `orx-biz:Person`, `orx-biz:owns`（情報的関係、知覚不可能）, `orx-biz:assignedRoom`。**提案** |
| 三系統融合 | C5 のスコアに「所有事前確率（台帳）」「最終目撃（時空間）」「視覚署名（埋め込み）」を統合（D1拡張） |
| 配達 | C2 スキルで対象を居室へ搬送（届け先＝owner の assignedRoom） |
| 触れるC | C1, C3（台帳・所有）, C4/C5（確率的同一化＋視覚署名）, C6（所有写像）, C7（特定・配達）, C8, C10 |
| 劣化ノブ | `occlusion_rate` / `pose_noise_sigma`（似た物体の弁別難度）, `id_read_failure_rate` |

## 5. タスク定義（採点）

- **入力**: 「{人物} の {物} を {届け先} へ」要求 ＋ 観測列（C9）＋ 入居者台帳。
- **決定**: 要求を満たす物理個体IRIの特定と配達先。
- **真値（C8 oracle）**: シム真値で各物体の真の所有者（種付け）と正解個体を導出。
- **採点**: 対象特定の正答率（似た候補からの一意選択）、配達成功率、同一性 F1、誤配達件数。

## 6. 実験条件

| 条件 | 期待 |
|------|------|
| B0 / B1 | 所有を結べず候補から選べない |
| OR−identity | 似た物体の混同で特定失敗 |
| OR-vec のみ | 「らしさ」は出せても所有が決まらない |
| **OR-full** | 三系統融合で一意特定 |

似た物体の密度・視覚難度を掃引して、所有（記号）と視覚署名（H4）それぞれの寄与を分離。

## 7. 指標

- 対象特定の正答率（一意選択）— 主指標
- 配達成功率・誤配達件数、同一性 F1
- 三系統（所有/時空間/視覚）の寄与分解（アブレーション）

## 8. 既存資産との関係

- **T1（同一性）** の C5/D1 に「所有事前確率」を加える拡張。**T2（業務‐物理）** の台帳結合（C3↔物理）
  と **T7/H4** の視覚署名を統合する、これまでのスイートの集大成的シナリオ。
- 新規は `orx-biz:owns` 等の情報的関係と、D1スコアへの所有事前確率の組み込み。

## 9. 実装メモ / コスト

- **中コスト**。所有関係の TBox／台帳種付け／D1スコアへの第3系統（所有事前確率）の統合が主作業。
- 「観測不可能な関係」を扱う点で OR の思想を最もよく示すが、検証の難度（似た物体の弁別）も高い。
