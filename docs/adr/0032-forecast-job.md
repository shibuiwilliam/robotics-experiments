# ADR-0032: 予測は周期ジョブで作り、地平を過ぎたら信念と突き合わせて採点する（M9-02）

- 日付: 2026-11-08
- 状態: 採択
- 触る層: reasoning（`forecasting`）、knowledge（`forecasts`、`LatentIndex.latest`）、scripts（`forecast`）、alembic 0014

## 文脈

`sbp.reasoning.prediction` は予測の型・採点（CRPS・被覆率）・信頼できる先行時間を持つが、予測を**作って書く**者も、
**採点して指標にする**者もいなかった（`forecast_coverage` / `forecast_crps` が未配線だった理由。H-24）。

## 決定

1. **予測の作り方**: 実体の最新の潜在を起点に、WM のロールアウトを `forecast_samples` 本（既定 30）、`forecast_horizon_steps` 刻み（既定 30）走らせ、
   先行時間ごと（`forecast_stride` 刻みおき＋地平の末端）に標本の潜在をプローブに通す。**確率は較正済みのプローブ出力**（不変条件 7）で、
   標本の分布が予測分布、区間は分位点、平均は標本平均。起点の潜在の不確実性は等方（`forecast_state_std`）— 索引は平均しか持たないため。
2. **保存は二重**: `predicted` のアサーション（平均、先行時間ごと。`horizon_origin` と `lead_time` つき。主信念の問い合わせに混ざらない）と、
   採点のための全体（区間・標本）を `forecasts` 表（alembic 0014）に JSON で。同じ `(拠点, 実体, フルーエント, WM 版, 起点)` は 1 件。
3. **採点**: 地平の終端から `forecast_grace_s` を過ぎた未採点の予測を、各先行時間の時刻の**信念の最新の推定**（0.5 以上なら 1、未満なら 0）と突き合わせる。
   信念がまだ無い点は数えず、1 点も揃わなければ採点せず次の周期に回す。実体・フルーエント・WM 版ごとに先行時間別の CRPS と被覆率を出し、
   `forecast_crps` / `forecast_coverage`（ラベル: entity, fluent, wm_version, lead_time_s）として書く。採点済みの印は一度だけ付く。
4. **ジョブ**: `make forecast`（`scripts/forecast.py`、`--watch N` で周期）。WM は `SBP_BRIDGE_WM_VERSION`、プローブは `--probe-id`（版を含む。WM 版が違えば落とす）。

## 結果

- 指標の配線済みが 23 になる（残りは identity 系の 2、H-27）。
- 予測が `predicted` で記録に残り、`as_of` で当時の予測を引ける（精度追跡）。

## 限界

- **採点の「実測」は信念であって真値ではない。** 運用には真値が無い（不変条件 10）。信念が誤っていれば採点も誤る。これは物理に対する精度ではなく、
  基盤の信念との整合である。真値での精度は SynthWorld を使うテストでのみ測る。
- 起点の不確実性が等方で、WM のアンサンブル（`LatentState.ensemble`）を使っていない。区間の被覆が名目から外れることがありうる（採点がそれを測る）。
- 先行時間の刻みは WM の階層（`mid`）の刻み幅で、潜在索引の時間間隔（エンコードの窓の刻み）と一致している保証はない（学習時に合わせる）。
- 実体・フルーエントは引数で明示する（索引の全実体を走らない）。実体の自動検出は未実装。
- 並行する 2 つの `forecast` は、同じ起点の予測を一意制約で二重にしないが、採点を二重にしうる（指標は `(名前, 時刻, ラベル)` で上書きされる）。
